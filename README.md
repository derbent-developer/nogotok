# НОГОТОК — интернет-магазин

Оборудование и расходники для салонов красоты. Дербент, ул. Ю. Гагарина, 25.
Сайт живёт на GitHub Pages, компьютер владельца для его работы не нужен.

**Адрес магазина:** https://derbent-developer.github.io/nogotok/
**Панель управления:** https://derbent-developer.github.io/nogotok/admin.html

## Как это устроено

Сайт — обычные файлы в этом репозитории, GitHub раздаёт их покупателям.
Каталог хранится в `data/db.json`, фотографии — в `assets/uploads`.
Панель управления открывается в браузере и сохраняет товары прямо в репозиторий
по ключу доступа GitHub. Через минуту после сохранения изменения видны на сайте.

Заказы не хранятся на сервере: покупатель заполняет форму, и заказ уходит
готовым сообщением в WhatsApp магазина. Переписка и есть история заказов.

## Вход в панель управления

1. Откройте `/admin.html` на сайте.
2. Вставьте ключ доступа GitHub (выдаётся один раз, см. ниже).
3. Работайте: товары, категории, настройки, баннеры.

### Как выпустить ключ доступа

1. github.com под аккаунтом `derbent-developer`
2. Settings → Developer settings → Personal access tokens → **Fine-grained tokens**
3. **Generate new token**, срок — год
4. Repository access → Only select repositories → **nogotok**
5. Permissions → Repository permissions → **Contents: Read and write**
6. Скопировать строку `github_pat_…` — это и есть ключ

Ключ заменяет пароль. Его нельзя показывать посторонним. Если он утёк — Revoke на
том же экране GitHub, и выпустить новый.

## Что умеет панель

| Раздел | Что делает |
|---|---|
| Товары | добавить, изменить, скрыть, скопировать, удалить; фото, цены, скидки, характеристики |
| Категории | разделы каталога, порядок в меню, значки |
| Заказы | памятка, куда приходят заказы, ссылка на WhatsApp магазина |
| Настройки магазина | контакты, номер WhatsApp для заказов, тексты, баннеры на главной |
| Безопасность | кто вошёл, отзыв ключа, скачать копию каталога |

## Правка через компьютер

Панель управления — основной способ, компьютер для неё не нужен.
Но если правите файлы в этой папке вручную:

1. Двойной клик по **открыть сайт локально.command** — посмотреть, что получилось.
2. Двойной клик по **обновить сайт.command** — отправить на сайт.

Скрипт сам сначала забирает правки, сделанные через панель, чтобы ничего не затереть.

При самой первой отправке git спросит логин и пароль от GitHub:
логин — ваш аккаунт, пароль — ключ доступа (обычный пароль GitHub тут не подойдёт).
macOS запомнит их в связке ключей, больше спрашивать не будет.

## Резервная копия

GitHub хранит историю всех изменений — любую правку можно откатить.
Дополнительно кнопка «Скачать копию каталога» в разделе «Безопасность».
